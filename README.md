# 白日梦

一款「聊天 + 朋友圈」形态的**角色陪伴应用**。你可以添加自己的梦角（虚拟角色 / 原创 OC），和它们聊天、发朋友圈、模拟通话、占卜、记录纪念日与日记，并自由定制大量美化内容。

> 当前版本：`v=20261003cx` · 纯前端 · 单机优先 · 数据全部本地存储

---

## 产品定位

- **目标用户**：有喜欢的虚拟角色 / OC，想和它们聊天、互动、记录日常的人。
- **核心形态**：小手机形态的聊天应用，网页端在线访问、数据存浏览器本地。
- **设计关键词**：轻量化 · 新手友好 · 不卡顿 · 深炭灰 + 淡紫 · 极简 · 超大圆角 · 轻微魔法元素。

---

## 技术栈

| 项目 | 说明 |
| --- | --- |
| 前端 | 原生 HTML + CSS + JavaScript（无框架、无构建步骤） |
| 数据存储 | IndexedDB（角色 / 聊天记录 / 字卡库 / 设置 / 表情包），KV 设置带 localStorage 兜底 |
| 图标 | 内联 SVG（细线条 · 圆角端点 · 24×24 · currentColor 继承） |
| 依赖 | 零第三方依赖，双击即可运行 |

## 目录结构

```
bairimeng/
├── index.html          # 应用入口（单页 SPA 骨架 + 各视图容器）
├── css/
│   └── style.css       # 全局样式（主题变量、玻璃拟态、动画、各组件）
├── js/
│   ├── db.js           # 数据层：IndexedDB 封装 + KV 设置读写
│   ├── icons.js        # SVG 图标库 + 自动填充 data-icon 占位
│   ├── cards.js        # 字卡系统（默认字卡、抽取、去重、导入净化）
│   └── app.js          # 主应用逻辑（所有视图、弹窗、交互、定时器）
└── README.md           # 本文件
```

> 脚本按 `db.js → icons.js → cards.js → app.js` 顺序加载，`app.js` 末尾调用 `init()` 启动。

## 运行方式

### 方式一：直接打开（最简单）

双击 `index.html` 即可在浏览器中运行（`file://` 协议）。

### 方式二：本地服务器（推荐，通知等 API 更完整）

```bash
# 在 bairimeng 目录下启动任意静态服务器，例如：
python -m http.server 8901
# 然后访问 http://127.0.0.1:8901
```

> 提示：改动代码后浏览器可能缓存旧版 JS，`index.html` 已内置 no-cache meta 标签 + 版本号 `?v=`，强刷（Ctrl+F5）即可加载最新代码。

## 核心功能清单

### 聊天
- 角色 / 群聊、聊天导航、角色分组
- 字卡随机回复、禁词过滤、关系语气倾向、禁用分组
- 消息气泡、图片、表情包、戳一戳、撤回 / 引用 / 转发 / 多选
- 角色主动发消息、查岗、随机戳一戳
- 角色昵称右侧「状态 · 时段」标签（凌晨 / 上午 / 中午 / 下午 / 傍晚 / 深夜六时段，到点自动重抽状态字卡）

### 朋友圈
- 玩家 / 角色发帖、点赞、评论、可见范围（公开 / 仅自己 / 部分可见 / 不给谁看）
- 关系网角色互相评论互赞，发帖角色对每个评论角色各回一条
- 玩家无限评论 / 回复，评论后发帖角色必回
- 角色发帖 / 评论 / 回复随机带表情包（图片优先、emoji 贴纸兜底）
- 超过 5 天的动态时间戳自动显示完整日期
- 评论 / 回复支持上传图片 + 选择表情包

### 个人主页
- 玩家资料、角色数量 / 聊天天数统计（自动刷新）
- 记忆宫殿、世界书、关系网、字卡库、聊天美化、表情包、聊天设置、数据管理、总设置
- 纪念日（支持年份输入，年月日均可填写）
- 入梦签（每日 0 点刷新，下次进入页面自动补弹）

### 加号细分功能
- **占卜**：传统韦特塔罗 78 张（大阿卡纳 22 + 小阿卡纳 56），牌背 / 牌面翻转、正逆位、三张牌时间流
- **记事簿**：记录事件，梦角到点提醒（年月日时分均可直接输入）
- **书信**：火漆印开信动画、梦角随机来信（开关 + 每日上限可配）

### 模拟通话
- 语音 / 视频通话、来电接听 / 拒绝、通话冲突保护（通话进行中其他来电静默忽略）

### 其他
- 表情包（上传 / 批量管理 / 上限 300 张）、字卡库（严格去重 + 分组管理）
- 关系网（朋友 / 恋人 / 家人 / 同事 / 陌生人 / 宿敌 / 仇人 / 厌恶）
- 数据管理（导入 / 导出聊天记录、清除聊天记录、清除冗余缓存）
- 聊天美化（气泡颜色、背景图、玻璃拟态模式、自定义 CSS）
- 通知（网页 Notification API）、低端机自动性能降级

---

## 数据存储说明

- 数据库名：`bairimeng`，版本 `2`
- 对象仓库：`characters`（角色）、`messages`（消息，含 charId 索引）、`kv`（键值设置）、`emojis`（表情包）
- 所有数据本地存储，不联网、不做账号系统；全局导入导出为统一单文件格式（`.ocdata`）
